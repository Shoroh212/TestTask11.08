# Тестовое задание — Unity

## Тест 1 — Сцена леса с дорогой

Создана небольшая зимняя лесная сцена с автомобильной дорогой.

В сцене присутствуют:

- заснеженный лес;
- деревья;
- кусты;
- пеньки и элементы окружения;
- автомобильная дорога;
- автомобиль;
- освещение и оформление сцены.

**Ссылка на выполнение:**

## Тест 2 — Сетчатая дорога и трафик

Создана сцена с сетчатой дорогой и 4 автомобилями:

- 3 автомобиля управляются AI;
- 1 автомобиль управляется игроком;
- реализовано автоматическое движение;
- по клику на AI-автомобиль управление передаётся игроку;
- предыдущий автомобиль игрока автоматически переходит под управление AI;
- реализовано переключение автопилота;
- автомобили ограничены физическими границами дороги.

### Управление

- `W` — вперёд
- `S` — назад
- `A` — налево
- `D` — направо
- `Space` — автопилот
